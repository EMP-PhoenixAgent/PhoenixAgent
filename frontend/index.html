Phoenix Agentv0.3.0
A fully-local, encrypted, autonomous coding & research agent.
100% local AES-256 at rest Argon2id + TOTP 2FA Rust + Tauri 2.0
Overview

Phoenix Agent is a desktop coding & research agent that runs entirely on your machine. Conversations, memory and tool output are stored in an encrypted SQLite database (SQLCipher) whose key is wrapped under a launch password you choose. Nothing leaves your computer unless you explicitly connect a cloud provider.

The agent can read and write files, search code, and run scripts — but every destructive action passes through an approval gate that you control.

The interface

The sidebar organizes everything the agent can reach — five panels, each with a clear job:

Modelslocal + cloud backends
Skillsreusable detailed memory
Toolsscripts the agent can call
Contextper-project orchestrator
Memorylong-term via MCP

The health bar across the bottom reports live status for Ollama/AmberCore, the active model, the database, ripgrep and the shell.

Core capabilities

What Phoenix Agent can do, under the hood.

🧠

Run models on-device through Ollama or AmberCore — no cloud GPU, no data leaving your machine.
☁️

Optionally route to any OpenAI-compatible Chat Completions API by registering a key.
🔐

All conversations and memory persist in a SQLCipher database, encrypted with AES-256 at rest.
✅

File read/write, grep and shell tools require your sign-off before any write executes.
📚
Skills
Reusable blocks of detailed memory and instructions, injected into the prompt when activated.
🗂️
Context
Short-term, per-project facts the agent reads and updates as it works — an orchestrator, not a vault.
🧩

Link external Model Context Protocol servers (or an Obsidian vault) as long-term memory.
🛡️
2FA recovery
Forgotten launch password? A TOTP code (RFC 6238) lets you back in to your encrypted data.
Security model

Phoenix Agent is built local-first: your data never has to leave your machine, and everything sensitive is encrypted at rest.

How the keys fit together

The database key is derived from a fixed internal password, then wrapped under your launch password and stored in keys.phx. On each launch the app unwraps it autonomously — you only ever type the launch password.

Recovery & privacy

Enable 2FA and an authenticator code becomes a recovery factor: lose the launch password and a current 6-digit code re-wraps the key. Telemetry (the Chronos protocol) is captured locally only, and is never transmitted unless you explicitly run the Prometheus test protocol.

AmberCore
A pure-Rust LLM runner. Drop-in Ollama-compatible backend.
Candle-based GGUF Port 42069 CPU · CUDA · Metal
Overview

AmberCore loads GGUF models and serves them over an Ollama-compatible HTTP API, so Phoenix Agent (or any Ollama client) can use it as its model backend — no Python, no separate runtime, just one binary.

Using it with Phoenix Agent

Start the server with ambercore serve, then point Phoenix at it — either from the Models panel, or by setting ollama_url = "http://localhost:42069" in ~/.phoenix/config.toml. Registered models appear automatically in the AmberCore box of the Models panel.
